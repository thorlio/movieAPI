ohMyFlix API Documentation

This documentation describes the RESTful API endpoints of ohMyFlix, a movie database server built with Node.js, Express, and MongoDB.

Key Features

  • Get a list of all movies
  • Get details of a specific movie by title
  • Get genre or director information
  • Register new users and manage accounts
  • Add/remove movies from a user's favorite list
  • Delete user accounts

Movie Endpoints

Method Endpoint Request Body Response
GET /movies Array of all movies (authentication required)
GET /movies/:title Movie object for the specified title
POST /movies { "title": "Movie", "genre": "Genre", "director": "Name" } Newly created movie object
PUT /movies/:title { "actors": ["Actor"] } Updated movie object
DELETE /movies/:title Confirmation message of deletion

User Endpoints

Method Endpoint Request Body Response
GET /users Array of all users (authentication required)
GET /users/:username User object for the given username
POST /users { "Username": "user", "Password": "pw", "Email": "email", "Birthday": "YYYY-MM-DD" } Newly registered user
POST /login { "Username": "user", "Password": "pw" } Authenticated user and JWT token
PUT /users/:Username { "Email": "new@email.com" } Updated user object (authentication required)
DELETE /users/:Username Account deletion confirmation (authentication required)
POST /users/:Username/movies/:MovieID Updated user with added favorite movie
DELETE /users/:Username/movies/:MovieID Updated user with removed favorite movie
